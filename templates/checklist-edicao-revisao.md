## 2. Promessa

- [ ] Promessa lida só do título + miniatura, em uma frase: `<escrever aqui>`
- [ ] O vídeo entrega essa coisa (não uma versão menor dela)
- [ ] A promessa começa a ser entregue nos primeiros minutos
- [ ] Nada que o título sugere está ausente do vídeo
- [ ] Teste de coerência promessa↔conteúdo rodado (ver `references/titulos-e-miniaturas.md`)

## 3. Estrutura

- [ ] Primeiros 5-10s entregam valor, sem vinheta/boas-vindas longas
- [ ] Roadmap presente no início
- [ ] Resposta principal não está escondida atrás de enrolação
- [ ] Loops pequenos abertos foram resolvidos
- [ ] Ritmo varia ao longo do vídeo
- [ ] Nenhuma ideia repetida sem acrescentar
- [ ] Fechamento resolve o motivo do clique, explicitamente
- [ ] Um CTA só, coerente com o objetivo deste vídeo
- [ ] Duração é consequência do assunto, não de uma meta

## 4. Packaging

- [ ] Título preciso, palavras importantes no início
- [ ] Miniatura personalizada (não frame automático)
- [ ] Miniatura vista em tamanho de celular ainda funciona
- [ ] Máximo 2-3 elementos visuais, sem poluição
- [ ] Título e miniatura comunicam a MESMA promessa
- [ ] Palavras do título são as que o público digita

## 5. Conteúdo sensível

- [ ] Nenhuma promessa de cura, garantia ou resultado universal
- [ ] Nenhum desencorajamento a procurar ajuda profissional
- [ ] Nenhuma prescrição individualizada — é informação geral
- [ ] Toda afirmação técnica foi validada pelo especialista (listar quais):
- [ ] Demonstração inclui orientação adequada ao público (condições, quando parar, quando procurar
      ajuda) — dentro da demonstração, não como aviso genérico no fim
- [ ] Tema sensível tratado de forma não-gráfica
- [ ] Relato de experiência pessoal e estudo citado estão com contexto
